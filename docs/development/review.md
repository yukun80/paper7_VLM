# 交付与定期复查清单

[返回本节目录](README.md) · [文档总目录](../README.md)

每次阶段交付、恢复长期搁置的工作，以及维护人主动安排的定期复查，都执行以下检查。

- 从根目录能否找到当前进度、设计、使用说明与讲解材料？
- 新增或移动的文档是否出现在目录，链接、章节和图片是否能打开？
- 命令参数、配置、输入要求是否仍与现有程序一致？只读帮助命令优先实跑。
- 功能变化是否同步对应说明？是否只更新进度而漏掉使用方式？
- 是否把尚未确认的方案、旧结果或演示运行写成新成果？
- 当前进度、阻碍和下一步是否过时？历史运行结果是否明确区分本次检查？
- 是否出现重复进度表、超长正文、散落在根目录的项目说明？
- 原始资料是否完整？模型、数据、实验产物是否被误改？

发现问题就在本次授权范围内修正并复查。检查结果更新[状态中的文档检查](../status/documentation-check.md)，不另建检查日志。涉及新研究方案或正式实验时，保留清楚的问题与授权边界，不自动启动。
